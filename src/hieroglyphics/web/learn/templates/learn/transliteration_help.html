Egyptological Transliteration

These letters show the consonants that hieroglyphs represent in Egyptian texts. Hieroglyphic spelling usually leaves out vowels, so it gives us only part of how the words sounded.

Value How to read the notation
ꜣ Aleph, also called alif. It looks a little like a 3.
ꞽ Yod. Some Egyptology books write it as j or i.
ḳ Dotted k. Some books write this as q.
ḏ Underlined d, also called the second d. The line distinguishes it from plain d.
wꜣ w followed by aleph. One hieroglyph can represent both letters.
